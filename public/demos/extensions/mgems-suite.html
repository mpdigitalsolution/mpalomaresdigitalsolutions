Chrome Extension Manifest V3 Technical Blueprint

Security & Sandboxing

Both extensions are built according to modern Chromium Manifest V3 specifications. Service workers handle token authentication, DOM injection occurs in isolated execution contexts, and API keys remain encrypted within client-side local extension storage.

Content Script Injection

Observes Google Keyword Planner DOM nodes (ads.google.com/aw/keywordplanner) and LLM interfaces (Claude, ChatGPT). Extracts active table rows and keyword volume without triggering Google Ads anti-scraping blocks.

MutationObserver • Isolated World • Zero CSS Contamination

Service Worker & Offscreen Fetch

Replaces legacy Manifest V2 background pages with event-driven background service workers. Executes streaming API calls to DeepSeek, OpenAI, Anthropic, and Google Gemini with auto-reconnection and exponential backoff.

chrome.runtime • Fetch API • Stream Readers

Zero-Leakage Key Security

All API keys for DeepSeek, Gemini, and OpenAI are stored exclusively inside chrome.storage.local with strict CSP sandboxing. No user telemetry or search queries ever leave the user's browser.

chrome.storage.local • Strict Content Security Policy
